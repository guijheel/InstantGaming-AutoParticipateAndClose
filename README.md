<h1 id="instant-gaming-auto-giveaway--close-">Instant Gaming Auto Giveaway &amp; Close 🎮</h1>
<p><a href="https://opensource.org/licenses/MIT"><img alt="License: MIT" src="https://img.shields.io/badge/License-MIT-yellow.svg"></a>
<a href="https://github.com/guijheel/InstantGaming-AutoParticipateAndClose"><img alt="Version" src="https://img.shields.io/badge/version-1.5.0-blue.svg"></a></p>
<p>Ce script Userscript permet d'automatiser entièrement la participation aux concours (giveaways) sur Instant-Gaming.com. Il clique sur le bouton de participation, valide les réseaux sociaux pour gagner des points bonus, et <strong>ferme l'onglet automatiquement</strong> une fois terminé.</p>
<h2 id="-fonctionnalités">✨ Fonctionnalités</h2>
<ul>
<li><strong>Participation Automatique</strong> : Clique sur le bouton "Participer" dès le chargement de la page.</li>
<li><strong>Bonus Sociaux</strong> : Simule les clics sur les boutons Discord, Instagram, X (Twitter), etc., pour maximiser vos chances (+1800 pts).</li>
<li><strong>Auto-Fermeture</strong> : Ferme l'onglet actif dès que le message "Merci pour ta participation" apparaît.</li>
<li><strong>Gestion de Liste</strong> : Commandes intégrées pour ouvrir tous les liens de concours depuis une liste.</li>
<li><strong>Affiliation automatique</strong> : Ajoute un paramètre partenaire pour soutenir le projet.</li>
</ul>
<h2 id="-installation">🚀 Installation</h2>
<ol>
<li>
<p>Installez une extension de gestion de scripts (type <strong>Tampermonkey</strong>, <strong>Violentmonkey</strong> ou <strong>Greasemonkey</strong>) sur votre navigateur.</p>
</li>
<li>
<p>Installez une extension :</p>
<ul>
<li><a href="https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo">Tampermonkey Chrome</a></li>
<li><a href="https://chromewebstore.google.com/detail/violentmonkey/jinjaccalgkegednnccohejagnlnfdag">Violentmonkey Chrome</a></li>
<li><a href="https://addons.mozilla.org/fr/firefox/addon/tampermonkey/">Tampermonkey Firefox</a></li>
</ul>
</li>
<li>
<p>Activer dans  <strong>Tampermonkey</strong>, <strong>Violentmonkey</strong> ou <strong>Greasemonkey</strong>  les Script users</p>
<h3 id="-configuration-importante">🔧 Configuration importante</h3>
</li>
</ol>
<p>Après avoir installé votre extension, vous devez activer deux options pour permettre au script de fonctionner pleinement :</p>
<ol>
<li>Ouvrez la <strong>Gestion des extensions</strong> de votre navigateur.</li>
<li>Cliquez sur <strong>Détails</strong> (ou Paramètres) de votre extension (Tampermonkey/Violentmonkey).</li>
<li>Activez l'option <strong>"Autoriser l'accès aux URL de fichier"</strong> (Allow access to file URLs).</li>
<li>Activez l'option <strong>"Autoriser les scirpts Utilisateurs"</strong> (Allow scirpt users).</li>
<li>Sans cela, certaines fonctions comme la détection automatique ou la fermeture d'onglet pourraient être bloquées.</li>
<li>Creé un "Nouveau script" et collez le code du fichier suivant :
<ul>
<li><a href="https://github.com/guijheel/InstantGaming-AutoParticipateAndClose/blob/main/script.js">Script.js</a></li>
</ul>
</li>
<li>Rendez-vous sur une page de concours Instant Gaming, le script s'occupe du reste ! (Etres Connecté)</li>
</ol>
<h2 id="-astuces--monter-son-compte-niveau-40">🏆 Astuces : Monter son compte Niveau 40+</h2>
<p>Pour augmenter votre crédibilité et vos chances, voici comment valider les succès de base sur IG :</p>
<ul>
<li><strong>✨ Rêveur</strong> : Ajoutez au moins <strong>5 jeux</strong> à votre <a href="https://www.instant-gaming.com/fr/wishlist/">Wishlist</a>.</li>
<li><strong>👥 Follow me</strong> : Ajoutez au moins <strong>un ami</strong> sur votre profil.</li>
<li><strong>🖼️ Hello world!</strong> : Ajoutez une <strong>image d'avatar</strong> à votre compte.</li>
<li><strong>📅 Ig New Visite</strong> : Connectez-vous simplement <a href="https://news.instant-gaming.com/fr">News</a>.</li>
<li><strong>🔌 Compagnon</strong> : Installez l'extension officielle Instant Gaming, puis désinstallez-la une fois le badge reçu.</li>
</ul>
<h2 id="️-utilisation">🛠️ Utilisation</h2>
<p>Le script ajoute des commandes spécifiques dans le menu de votre gestionnaire de scripts (Tampermonkey) :</p>
<ul>
<li><strong>Participate &amp; Close</strong> : Lance la séquence de participation et ferme l'onglet.</li>
<li><strong>Socials</strong> : Clique uniquement sur les bonus sociaux restants.</li>
<li><strong>Giveaway List</strong> : Récupère les liens des concours présents.</li>
<li><strong>Open ALL Links</strong> : Ouvre tous les concours détectés dans de nouveaux onglets.</li>
</ul>
